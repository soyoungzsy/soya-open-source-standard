# 产品与新手入口

默认读者是非技术用户。写作及验收先遵循 [非技术用户可读性标准](plain-language.md)。

## README 内容

中文 README.md，英文 README.en.md；已有项目沿用其语言路由。两种语言独立完整且互相链接。

1. 首屏：Soya 功能型标题、中英功能一句话、最短入口和输入→输出示例。
2. 背景：从个人需求提炼普适问题，解释与现有方法的差别；标记真实实践、合成示例与计划，不编造评价和数据。
3. 场景与用户：什么人、何时、输入什么、得到什么；不适用情形与效果边界。
4. 快速开始：账号、系统/宿主、模型、费用、必要权限；主路径和失败后的替代路径。
5. 示例：可公开输入、实际得到的输出、成功判断；AI 随机输出以结果特征验收。
6. 安装、升级、卸载：固定版本入口、配置/数据位置、备份与保留用户设置。
7. 数据处理：哪些数据给哪个服务、为何需要权限、留存/清除机制。未知行为不能宣称零留存。
8. 故障与支持：版本、复现、脱敏日志；安全问题走可用私密渠道。
9. 版本、CHANGELOG、Release、许可证、第三方归属、贡献方式和维护状态，不承诺未建立的 SLA。

## 可复制 Prompt

GitHub 代码块通常有复制控件。放完整 fenced code block 和独立纯文本入口；不在静态 README 加无效 JavaScript。Prompt 写清任务、输入、输出、缺失输入与隐私规则。

```text
请按 Soya 项目开源规范整理以下个人方法。
输入：[粘贴我有权公开的方法，不含个人敏感信息和工作机密]
输出：定位、中英介绍、最短使用路径、合成示例、风险与发布检查。
缺失事实标为待确认，不从其他对话补私人信息，不编造测试和发布成功。
修改、合并或发布仓库时仅在我授权的目标和范围内执行。
```

纯 Prompt 是轻量入口，不承诺等于宿主安装 Skill 后的完整能力。

## Skill 与可运行项目

- 说明支持并验证过的宿主。安装命令和路径须按当前官方说明核实，不能猜 `npx` 包名或把纯聊天工具说成支持安装。
- 新手入口：复制项目链接给支持 Skill 安装的助手，请它检查内容、确认宿主安装方式、备份同名旧版、安装并验证可调用。
- 离线入口：下载固定 Release 的 Source code ZIP，将包含 SKILL.md 的完整目录放在宿主支持的技能目录，保留 references/scripts，再重启或新建会话验证。
- 给一个可发送的首次调用句、必要输入与预期结果，提供旧版本恢复和卸载步骤。
- 应用优先提供实际可用演示；本地运行则给完整可复现步骤，不用术语替代用户操作。
- 用户密钥在本地配置，示例用显然虚构值；客户端不嵌入服务端密钥。

## 适量工程材料

所有项目含 LICENSE、CHANGELOG、故障和隐私说明；协作项目补 CONTRIBUTING、Issue/PR 模板；执行代码/接收数据的项目补 SECURITY、依赖锁定和必要 CI；应用补运行架构、配置、部署与数据恢复。内容可以整合，不机械生成空文件。
