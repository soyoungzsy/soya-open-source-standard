# 发布、提报和恢复

## 请求与终点

| 请求 | 终点 |
| --- | --- |
| 整理/评审 | 完成整理，不自行公开 |
| 修改提报 | 可审查 PR，报告待合并 |
| 发布 GitHub | 公开仓库、固定 tag、正式 Release、公开获取验收 |
| 发布在线应用 | 上述事项及实际部署与功能验证 |

沿用该项目已有授权，此 Skill 不授予所有仓库永久写权。核实账号，不混用连接器和浏览器的不同身份。状态不确定先读远端，避免重复发布。

## 版本

初始试验版本默认 0.1.0，稳定接口可从 1.0.0 起。修复增 patch、兼容功能增 minor、稳定版破坏性变化增 major；0.x 破坏变化至少增 minor，并写迁移。

用 VERSION 或原生包元数据作为唯一版本源，保证 CHANGELOG、vX.Y.Z tag 和 Release 一致。已发布 tag 不移动、旧包不静默替换。Release 说明价值、兼容性、升级/降级、实际验证与限制。未完成计划不能写成已上线。

## AI 提报

记录基线提交与用户未提交工作，使用分支/隔离目录，不覆盖用户修改。审阅完整 diff，排除泄露、越界和无关依赖。PR 说明问题、前后行为、影响、实际测试/未测项、回滚与版本，不上传原始聊天和私有分析。

有合并/发布授权就继续执行；分支保护要求审阅时遵守规则并报告阻塞，不关闭保护绕过。验收目标提交的真实 CI 和实际发行物，不编造通过。

## 回滚

| 对象 | 机制 |
| --- | --- |
| 本地 Skill/工具 | 备份同名旧目录，提供旧 Release，保留用户配置 |
| 共享代码 | 优先 git revert 并发补丁，不默认 reset 或 force-push |
| 在线部署 | 恢复旧的已验证发行物，验证关键功能 |
| 数据 | 写前备份、明确迁移兼容性、验证恢复；回滚代码不代表恢复数据 |
| 外部动作 | 说明能否补偿及不可逆部分，不承诺全部可撤回 |
| 泄露 | 撤销凭据与控制传播，普通回滚不消除泄露 |

可下载构建包提供校验和，保留已验证版本。失败版标记已知问题并发修复，不覆盖旧记录。

## 问题处理

Issue 收集版本、环境、复现、预期/实际、脱敏日志，提示勿附私人或工作资料。SECURITY 指向确实可用的私密报告渠道，不虚构邮箱；无渠道先配置平台私密报告或明确暂不接收敏感报告。

认证问题核实账号、权限，不要求用户在聊天粘贴 token。限流遵守返回提示，网络有限重试。中断记录已完成步骤、远端对象与恢复点，不重复建仓/tag/Release。

## 回执

项目与一句话功能；准确状态；真实仓库 URL；版本、commit SHA、Release URL；最短使用；实际验证和未测项；发布后第三方视角自检（疑问、修订、复查与剩余项）；旧版入口与数据注意；阻塞及最小解除动作。
